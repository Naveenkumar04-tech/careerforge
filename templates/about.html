Student Career & Job Recommendation System

A full-stack, rule-based career analytics engine designed for computer science students and fresh graduates.

Project Motivation & Goal

Transitioning from college academics to entry-level tech roles can be overwhelming for computer science students. Students often lack clarity on which industry roles match their existing skill set, what specific technologies they need to learn next, and how employability ready they are.

This application solves this problem by providing transparent, data-driven profile evaluations, calculating career readiness scores ($0-100$), ranking 12 high-demand software job roles, and generating a personalized 6-month learning roadmap.

System Architecture

User Browser (HTML5/CSS3/JS/Bootstrap 5)
    ↓ HTTP Form / REST Requests
Flask Web Server (Python 3.14)
    ├–– Routes Layer (Blueprints: main_bp, student_bp)
    ├–– Service Layer (Recommendation Engine, Scoring Engine, Roadmap Generator)
    ├–– Model Layer (PyMongo Client + In-Memory Fallback Store)
    ↓ JSON Documents
MongoDB Database (`students` collection)

Recommendation & Scoring Algorithm Formula

For each of the 12 job roles, a compatibility score ($0-100\%$) is calculated across 6 weighted components:

  • Technical Skills (40%): Evaluates required vs preferred skill overlap using Jaccard coverage.
  • Education & CGPA (15%): Evaluates CGPA threshold against minimum role expectations.
  • Practical Projects (15%): Evaluates quantity and technical detail of completed portfolio projects.
  • Certifications (10%): Matches industry certifications with role domain keywords.
  • Interests (10%): Checks domain interest alignment (Web, Cloud, Data, Security, etc.).
  • Experience Level (10%): Considers Beginner, Intermediate, or Advanced level.
